# Zymbly web app

Interactive pixel-cloud landing page for Zymbly, built with Next.js.

## Local development

```bash
npm install
npm run dev
```

The app runs at [http://localhost:4567](http://localhost:4567).

## Production check

```bash
npm run lint
npm run build
```

## Deploy to Vercel

Import this repository into Vercel and keep the auto-detected Next.js settings.
No runtime environment variables or custom `vercel.json` configuration are
required. The local `FAL_AI_KEY` was used only to create the committed visual
assets and is not read by the application.
